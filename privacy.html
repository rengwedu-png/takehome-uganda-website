VALIDATION

Validate before building payments

The first objective is not revenue. It is evidence that users want the premium report.

Test sequence

  1. Show the premium offer after a completed calculation.
  2. Track CTA views and clicks with analytics.
  3. Send interested users to a simple “coming soon” page.
  4. Collect only voluntary contact details if you later add a waitlist.
  5. Compare demand at UGX 5,000 and UGX 10,000.

Decision thresholds

  • Weak: very few CTA clicks → improve the offer.
  • Promising: consistent clicks → build a payment flow.
  • Strong: users ask when it will launch or volunteer to buy → prioritize payment integration.

These are product-testing heuristics, not guarantees.
